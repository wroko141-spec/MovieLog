# MovieLog - дневник фильмов

Учебный проект по УП.05 «Проектирование и разработка информационных систем».
Автор: Закиров Радель Рустемович.

MovieLog - веб-приложение, где пользователь ведёт дневник просмотренных фильмов:
добавляет фильмы из каталога, ставит оценки, пишет отзывы и получает подборку
фильмов под настроение с помощью ИИ.

## Что умеет
- регистрация, вход по логину или email, выход;
- восстановление пароля по email (одноразовая ссылка на 30 минут, в базе хранится только SHA-256 хеш);
- каталог фильмов с поиском и фильтром по жанрам;
- личный дневник: «Хочу посмотреть» / «Посмотрел», оценка 1-10, отзыв, дата просмотра;
- статистика: сколько посмотрено, средняя оценка, любимые жанры;
- подбор фильмов по настроению с помощью ИИ (учитывает оценки, советует только непросмотренное);
- панель администратора: фильмы, жанры, пользователи, отзывы;
- адаптивная вёрстка (телефон, планшет, компьютер), страница 404.

## Технологии
- Python 3.12, Django, Django REST framework
- PostgreSQL 16
- HTML5, CSS3, JavaScript
- Git, GitHub

## Роли
- **Пользователь** - ведёт свой дневник, ставит оценки, получает подборки ИИ.
- **Администратор** - ведёт каталог фильмов и жанров, управляет пользователями.

## Запуск
```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env            # указать пароль от PostgreSQL
createdb movielog_db
python manage.py migrate
python manage.py seed_movies      # демо-каталог
python manage.py createsuperuser
python manage.py runserver
```
Сайт откроется на http://127.0.0.1:8000. Без PostgreSQL можно запустить на SQLite: `USE_SQLITE=1 python manage.py migrate` и так же для остальных команд.

Письма для восстановления пароля без настройки почты выводятся в консоль. Для настоящей отправки заполните `EMAIL_*` в `.env`.

## ИИ
Подбор работает через любой API, совместимый с OpenAI `chat/completions` (`AI_API_URL`, `AI_API_KEY`, `AI_MODEL` в `.env`).
Если ключ не указан или сервис недоступен, работает встроенный подбор: жанры по словам из настроения плюс любимые жанры пользователя.

## REST API
| Метод | Адрес | Что делает |
|---|---|---|
| GET | `/api/movies/?q=&genre=` | каталог, поиск |
| POST/PUT/DELETE | `/api/movies/` | только администратор |
| GET, POST | `/api/diary/` | свои записи дневника |
| PATCH, DELETE | `/api/diary/<id>/` | изменить или удалить свою запись |
| GET | `/api/stats/` | статистика пользователя |
| POST | `/api/recommendations/new/` | подбор ИИ по настроению (10 раз в минуту) |
| GET | `/api/recommendations/` | история подборок |

## Безопасность
- пароли хранятся как хеш (PBKDF2), токены сброса - как SHA-256;
- CSRF-защита форм и API (токен в заголовке X-CSRFToken);
- запросы к базе через ORM - нет SQL-инъекций;
- шаблоны экранируют вывод, JS вставляет данные через textContent - нет XSS;
- пользователь видит и меняет только свои записи;
- ограничение частоты запросов к API и ИИ.

- `db/schema.sql` - SQL-скрипт структуры базы
- `docs/diagrams/` - UML-диаграммы и ERD (draw.io)
